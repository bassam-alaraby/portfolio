Al Qadia Momken

{Tribute Countdown Page · AI-Assisted}

A fully static tribute page dedicated to "القاضية ممكن" — Mohamed Magdy Afsha's legendary winning goal in the 2020 CAF Champions League Final. The page tracks exactly how much time has passed since that moment.

What it does

  • Live timer since Afsha's winning goal — years, days, hours, minutes, and seconds
  • A running counter of how many Fridays have passed since the match
  • Match overview and full goals timeline
  • Minimal cinematic design inspired by Al Ahly and the CAF Champions League
  • Fully responsive layout with subtle smooth animations
  • Built with pure HTML, CSS, and vanilla JavaScript
